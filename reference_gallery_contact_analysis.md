# Reference Gallery and Contact Analysis

## Product gallery interaction

The reference product page uses a desktop two-column commerce layout: a narrow vertical thumbnail rail, a dominant rectangular selected-image stage, and a purchase ledger placed beside the gallery. The thumbnail rail contains several distinct product views, the active thumbnail is visually framed, and selecting a thumbnail changes the large stage image without leaving the product page. The large stage keeps a tall editorial crop, while the order fields sit in the adjacent purchase area.

For Panco, the implementation will preserve this interaction pattern using original Panco images and labels. The gallery should retain a stable primary image, distinct supporting images, a framed active thumbnail, and a tall selected-image stage. Panco will not reuse the reference brand, product photography, product names, copy, or review content.

## Contact-page interaction

The reference contact page is intentionally concise: a small communication label, a clear page title, a short explanatory sentence, and direct communication actions. For Panco, the corresponding page will use original Panco editorial copy and a customer inquiry form, supplemented by appropriately configured contact channels only after their actual links are provided. No reference text, phone number, social handle, logo, or footer content will be reused.
